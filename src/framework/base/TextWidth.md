# TextWidth 模块 (src\framework\base\TextWidth.h)

## 概述

文本宽度折算:按等宽终端口径计算一段文本占多少列。纯函数模块, 无状态、无实例、不分配内存、不抛异常,
可在任意线程调用。

本模块属 **framework 层**, 不依赖工程内任何其它模块, 只依赖 C 运行时; 不认识字体、不接触渲染设备,
也不做文本排版(折行、截断、对齐一律归调用方)。

计数口径:东亚宽字符(Unicode 东亚宽度 W 与 F)计 2 列, 组合符、零宽字符、方向控制符与 C0 控制字符计 0 列,
其余可打印字符计 1 列。宽度区间表、UTF-8 解码器与模式名比较均为文件内实现, 不对外暴露。

本模块包含以下编程接口:

### 函数

| 函数 | 说明 |
| --- | --- |
| `CalcTextWidth` | 计算文本在等宽终端口径下的显示宽度(列数)。 |

本模块不定义公开类型与公开常量。

## CalcTextWidth 函数 (TextWidth)

计算文本在等宽终端口径下的显示宽度。

### 语法

```cpp
int CalcTextWidth(
  [in] const char* text,
  [in] const char* mode = "utf-8"
);
```

### 参数

`[in] text`

类型: **const char\***

以 `\0` 结尾的待测文本(按 `mode` 指定的编码解释)。为 `nullptr` 时直接返回 `0`, 不解引用、不读任何字节。
缓冲须在调用期内保持有效, 本函数不复制也不修改它。

`[in] mode`

类型: **const char\***

编码模式名, 大小写不敏感, 默认值为 `"utf-8"`。合法域:

- `"utf-8"` / `"utf8"` / `nullptr` : 按 UTF-8 解码计数。
- 其它任意字符串 : 按单字节处理 —— 每字节独立判宽, 控制字符计 `0`, 其余计 `1`(不做多字节解码)。

传入非法模式名不报错, 静默走单字节分支。

### 返回值

类型: **int**

显示宽度(列数)。空文本返回 `0`; `text` 为 `nullptr` 返回 `0`。UTF-8 模式下的非法字节按 1 列计
(每遇一个非法首字节只前进一个字节, 后续字节按新首字节重新判定), 因此结果不会因输入损坏而中断或回退。

### 注解

UTF-8 模式的判定细则:代理区码点、过长编码(长度与码点不匹配)、超出 `U+10FFFF` 的码点、以及截断的多字节
序列一律视为非法, 按 1 列计。零列字符集合包含变体选择符、零宽连接符一类不可见码点, 因此视觉上不可见的
字符不占列。

单字节模式只用于"非 UTF-8 的窄字符终端"一类场合; 中文等多字节文本在该模式下会按字节逐个数列,
不反映实际显示宽度 —— 需要按显示宽度布局时一律用 UTF-8 模式。

本函数是**纯函数**: 无全局状态、无缓存、不修改入参, 同一输入恒得同一输出。开销与文本长度成正比
(逐码点线性扫描区间表), 不含堆分配; 不保存任何指针, 调用后入参可与本模块无关。
