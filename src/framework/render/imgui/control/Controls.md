# Controls 模块 (src\framework\render\imgui\control\Controls.h)

## 概述

控件层:把一枚 `CtrlInfo` 画成像素、把控件自身的交互结论回传给该控件绑定的事件处理器。对外入口 = 逐控件绘制
(`DrawCtrl`)、逐类型绘制实现(`TitleBar` / `Button` / `InputSingle` …)与容器的绘制接口表(`GetCtrlApi` ⇒ `CtrlApi` 3 项)。
控件库逐枚无状态被调用,不持有控件数据、不分配控件对象、不遍历布局;**控件缓冲的装配与回收不归本模块**
(见 `framework/base/CtrlBuffer.h` 与 `framework/layout/LayoutBuilder.h`)。

本模块属 **framework 层 · 控件库 · 控件**(部件实现在同目录 `Widgets`)。依赖方向一律向下:
上下文类型与投影配色取自 `BasicDesign`,类型身份与操作码取自 `ControlSpec`,缓冲结构与取址辅助取自 `CtrlBuffer`,
绘制单元取自 `Widgets`(部件层),接口表类型取自 `render/Render.h`,当前渲染窗口取自宿主件;不感知布局文档解析、
几何解算、应用状态与设备层。

**不做什么**:不解析布局文档、不按几何系数解算像素矩形(由 `GeometrySolver` 在装配期完成)、不持窗口句柄与
D3D11 设备及纹理生命周期(标题栏只上报期望坐标,纹理由宿主注入)、不做鼠标点击的二次判定(是否由渲染出口补判
以 `ControlSpec.h` 的类型谓词为准)。控件接口统一为单参数 `VOID Xxx(CtrlInfo* info)` —— 外部一次性送入,控件自行
拆解任务;列表控件由控件自身逐行送入内部管道部件。

文件内件(控件绘制分派表、配色样式表、取色与层号辅助、矩形绘制辅助、无效缓冲占位串)均为文件作用域 `static`,
不属公开面,不单列。

本模块包含以下编程接口:

| 函数 | 说明 |
| --- | --- |

| `Button` | 绘制按钮并在点击时调用控件自身事件处理器。 |

| `Slider` | 绘制单手柄滑动条,值变更时回传编辑变更操作码。 |
| `Progress` | 绘制进度状态显示件,可见期间每帧回传进度更新操作码。 |
| `RenderSurface` | 绘制渲染面(有纹理等比居中,无纹理画占位面)。 |
| `CheckBox` | 绘制原生复选框,勾选态改变时回传编辑变更操作码。 |
| `Combo` | 绘制下拉框,值或选项变更时回传编辑变更操作码。 |

`framework/base/CtrlBuffer.h`, 整枚布局的缓冲回收(`FreeLayoutCtrlBuffers`)与控件信息装配(`BuildCtrlInfoFromSpec`)在
`framework/layout/LayoutBuilder.h`; 上述符号的语义以各自模块的接口文档为准。

## UpdateContext 函数 (Controls)

刷新逐帧绘制上下文。

### 语法

```cpp
BOOL UpdateContext(CONST AutoSize& refsize, CONST ProjCR* pProj, CONST vec2* pWndPos, CONST vec2& orgContent);
```

### 参数

`[in] refsize`

类型: **CONST AutoSize&**

参考尺寸对象。函数按其当前设计系数取出一份像素值(控件高 / 字号 / 内边距 / 间隔)存为本周期的参考尺寸,
对象本身不被持有,调用返回后即可失效。

`[in] pProj`

类型: **CONST ProjCR\***

本帧投影配色,宿主持有。控件库此后一律按"绘图层号 + 槽位"从它取色,不读 ImGui 样式槽。
传 `NULL` = 本帧未注入配色,取色一律得到 `0`(该处不着色),绘制路径不因此失败。

`[in] pWndPos`

类型: **CONST vec2\***

本窗口的位置记录槽(基座布局里 `WND` 控件的 `position`)。标题栏一类窗口级控件据此取拖动基线。
传 `NULL` = 本窗口无位置记录(内嵌 flex 窗口),此时标题栏退回读真实窗口矩形。

`[in] orgContent`

类型: **CONST vec2&**

内容容器原点(窗口本地坐标),即内容控件**有效坐标**的零点。控件库据此把每枚内容控件的有效坐标换算成
容器本地坐标后再绘制(容器已提供裁剪与偏移,换算只做一次)。无内容容器时可传 `(0,0)`。

### 返回值

类型: **BOOL**

恒为 `TRUE`,无失败路径。返回值只为与调用方既有形态保持一致,不应作为可用性判据。

### 注解

每帧渲染布局之前调用**一次**,先后顺序为 `UpdateContext` → 逐控件 `DrawCtrl`。重复调用以最后一次为准。

副作用有三处,均对调用方可见:①控件库上下文被整体覆盖;②转调部件层上下文(`Widgets::UpdateContext`)
刷新参考尺寸、投影配色与编辑中计数 —— 这是逐帧唯一的写点;③改写 ImGui 全局样式三项(`WindowPadding`
置零、`FramePadding` 取设计内边距、`FrameRounding` 取本帧圆角),因此本函数必须在窗口内提交控件之前调用,
并会覆盖宿主样式回调对这三项的设置。

本帧圆角 = 设计内边距;非根窗口级圆角一律取该值,根窗口圆角仍由宿主样式回调给出。

## HasActiveInput 函数 (Controls)

查询本帧是否存在处于编辑中的输入控件。

### 语法

```cpp
BOOL HasActiveInput();
```

### 参数

此函数无参数。

### 返回值

类型: **BOOL**

`TRUE` = 本帧至少有一个输入控件的 ImGui 项处于激活态(编辑中);`FALSE` = 无。

### 注解

计数归部件层:输入部件在自身项激活时累加,由 `UpdateContext` 每帧复位。因此本函数只在本帧
`UpdateContext` 之后、下一次 `UpdateContext` 之前有意义。

渲染出口据此决定是否关闭输入法(编辑中不推 IME 开关);控件库自身不依据该状态改变绘制。

## DrawCtrl 函数 (Controls)

逐控件绘制入口:换算绘制坐标、定位控件矩形后按类型分派绘制实现。

### 语法

```cpp
BOOL DrawCtrl(CtrlInfo* ctrl);
```

### 参数

`[in] ctrl`

类型: **CtrlInfo\***

控件信息指针。函数不判空,调用方须保证非 `NULL`;矩形原点取 `ctrl->position`(有效坐标 = 窗口本地坐标,
内容控件已含父链累计偏移),矩形尺寸取 `ctrl->size`。控件缓冲按各绘制实现自己的约定读取。

### 返回值

类型: **BOOL**

`TRUE` = 该控件**有绘制实现**(含未知类型的矩形占位与各类"声明即有像素"的绘制);`FALSE` = 未使用槽位
(`CTRL_TYPE_INVALID`)、或该类型在分派表中没有绘制实现(`LIST` / `LIST_TIMESPAN` 一类)。

返回值表示"是否走了绘制实现",**不表示本帧是否真的产出了像素**:已知类型的绘制实现在缓冲缺失时可能
直接返回(见 `Slider` / `Combo` / `Progress`),此时返回 `TRUE` 而像素为零。

### 注解

**坐标换算**:内容控件在内容容器内绘制,而容器已提供裁剪与原点偏移 ⇒ 本函数在进入分派前把
`ctrl->position` 临时换算为**容器本地坐标**(有效坐标 − `UpdateContext` 注入的内容容器原点),分派结束
还原为有效坐标。逐类型实现一律从 `CtrlInfo::position` 取原点,因此换算只此一处;声明坐标始终保留在
`posDeclared`,不受影响。因此**绘制期内**(含分派中触发的事件处理器回调)读到的 `position` 是容器本地
坐标;需要窗口本地坐标的消费方应在绘制之外取(`position` 在分派返回后即为有效坐标)。结构件
(`WND` / `TITLE` / `CNTR`)不换算:它们的坐标已是窗口本地坐标(`WND` 为桌面位置),且 `TITLE` 由
`LayoutRender` 直接调用 `TitleBar` 绘制。

三条分派路径,任一情况都必须提交占位项:①未知类型(`CTRL_TYPE_UNKNOWN`)画矩形占位;②未使用槽位
(`CTRL_TYPE_INVALID`)只占位不画;③已知但无绘制实现者零像素占位。原因是 ImGui 对"只推进光标而
不提交任何项"的控件会逐帧报 `SetCursorPos() to extend window/parent boundaries` 错误。

"声明高生效"(有外框则以声明高为外框高、无外框则以声明高为项高)由各部件自身负责 —— 部件自知是否
画外框,控件层不按控件类型推入样式。

前置条件:ImGui 帧内、目标窗口的 ImGui 窗口已建立,且本帧已调用 `UpdateContext`。

## TitleBar 函数 (Controls)

绘制标题栏控件并回传标题状态。

### 语法

```cpp
VOID TitleBar(CtrlInfo* info);
```

### 参数

`[in] info`

类型: **CtrlInfo\***

标题栏控件信息。标题文本取控件缓冲自身(C 串),缓冲为空或缺失时按空串绘制;右上关闭钮恒绘制,
可交互标题区相应让出右侧关闭钮宽度。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

**操作码**:公共段 = 组合位 —— 按住中(`OPER_COMMON_HOLD`,电平)/ 激活(`OPER_COMMON_ACTIVE`,沿)/
失去激活(`OPER_COMMON_DEACTIVATED`,沿)/ 双击(`OPER_COMMON_DOUBLECLICK`,沿);专属段 = 结构件族的
`OPER_STRUCT_TITLE_CLOSE`(关闭钮被点击);搭载段恒 0(未搭载)。整字为 `OPER_NONE` 时不回调。

**参数槽**:按住期间 `param` = 窗口期望位置(桌面像素坐标,由抓取偏移与当前光标算出,打包形态见
`ControlSpec.h` 的 `PackWndPos`);其余情形 `param` = `0`(无位置请求)。`data` = 控件缓冲。

**只上报、不落地**:标题栏不调任何窗口 API,也不改写位置记录。期望位置由该控件绑定的事件处理器记进
窗口的位置槽,渲染出口在下次取得渲染目标时结算为实质移动 —— 未绑定事件的窗口因此不可拖动。

**拖动基线**:抓取偏移在拖动首帧建立(光标相对窗口左上角),拖动全程保持,故期望位置与窗口当前位置无关,
不会逐帧累加。首帧的窗口当前位置默认读窗口位置记录槽(`UpdateContext` 的 `pWndPos`),该窗口无记录时
退回真实窗口矩形;两个来源都取不到则不建立拖动(本帧不产出坐标)。

**命中区**:所有公共位一律限定本控件命中区;悬停与"鼠标按下"属原始输入事实,不上报。

**拖动状态为函数级静态**:同一时刻至多一个窗口的标题被按住;复位只在状态所属窗口上发生,否则别的窗口的
标题栏会清掉进行中的拖动。

## Button 函数 (Controls)

绘制按钮并在点击时调用控件自身事件处理器。

### 语法

```cpp
VOID Button(CtrlInfo* info);
```

### 参数

`[in] info`

类型: **CtrlInfo\***

按钮控件信息。按钮文字取控件缓冲首址(C 串),缓冲缺失时按空串绘制。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

**操作码**:公共段 = 部件给出的公共位图(完整单击即 `OPER_COMMON_CLICKED`),专属段与搭载段均为空;
`param` = `0`,`data` = 控件缓冲。公共位图为空(本帧无操作)或未绑定事件处理器时不回调。

**取色**:按钮面 = 本控件自身层次对应的层号(按钮声明在容器父链下 ⇒ 层次相对容器上浮一档,故比相邻输入框、
下拉框更亮一档);三态(常态 / 悬停 / 激活)与该层对比槽取色由控件层采样成成品配色方案后交给部件,
部件不接触层号。

## Text 函数 (Controls)

绘制静态文本;绑定事件时另补一枚覆盖控件矩形的无绘制可交互项。

### 语法

```cpp
VOID Text(CtrlInfo* info);
```

### 参数

`[in] info`

类型: **CtrlInfo\***

静态文本控件信息。文本取控件缓冲首址(C 串),缓冲缺失时按空串绘制;文本在控件矩形内垂直居中,
纵向由部件在声明高内居中,横向自矩形左缘起排。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

**操作码**(仅绑定事件时):公共段 = `OPER_COMMON_CLICKED` / `OPER_COMMON_RIGHTCLICK` /
`OPER_COMMON_DOUBLECLICK` 的位或,专属段与搭载段为空;`param` = `0`,`data` = 控件缓冲。

未绑定事件处理器时不创建任何 ImGui 项(像素与 ImGui 状态零变化);补的可交互项本身不产生任何绘制。
"单击"按完整单击口径判定(左键在本项命中区内释放),按下帧不报,避免"按下即响应"歧义。

**取色**:文本色 = 本控件层次的对比槽,随层次变化。

## Rect 函数 (Controls)

绘制纯矩形控件;绑定事件时另补一枚覆盖控件矩形的无绘制可交互项。

### 语法

```cpp
VOID Rect(CtrlInfo* info);
```

### 参数

`[in] info`

类型: **CtrlInfo\***

矩形控件信息。绘制矩形 = 控件声明矩形(圆角底面 + 圆角描边),无文本、无子内容;颜色全取投影。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

**操作码**(仅绑定事件时):与 `Text` 同 —— 公共段为单击 / 右键 / 双击的位或,`param` = `0`,
`data` = 控件缓冲。

**层号口径**:矩形原点取分派入口 `DrawCtrl` 定位后的光标屏幕位置;层次由控件自身表达(`CtrlInfo::nLayer`
已在装配 / 增删时按父链递推完毕)⇒ 绘制只取该层次,不做帧内几何回溯。本件不感知
悬停 / 激活状态,状态一律交给投影槽位;描边恒取边框常态层。

## InputSingle 函数 (Controls)

绘制单行输入控件。

### 语法

```cpp
VOID InputSingle(CtrlInfo* info);
```

### 参数

`[in] info`

类型: **CtrlInfo\***

输入控件信息。文本区由缓冲首址与容量共同给出(取址口径见 `CtrlBuffer.h` 的 `CtrlTextRangeOf`);
无专用缓冲时按只读占位绘制(显示固定占位串"无效缓冲",容量 `0`)。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

**操作码**:专属段 = 编辑族 `OPER_EDIT_SUBMIT`(回车或失焦且有改动时提交),公共段可带部件给出的公共位图,
搭载段恒 0;`param` = `0`,`data` = 控件缓冲。部件返回 `0`(本帧无操作)或未绑定事件处理器时不回调。

**取色**:下沉样式 —— 输入域相对所在层次下沉一档(输入类控件同口径)。

前置条件:控件缓冲容量须含结尾 `\0`;容量为 `0` 时按只读项处理,不写回任何文本。

## InputMulti 函数 (Controls)

绘制多行文本输入控件。

### 语法

```cpp
VOID InputMulti(CtrlInfo* info);
```

### 参数

`[in] info`

类型: **CtrlInfo\***

多行输入控件信息。缓冲为文本类缓冲(首址即 C 串),容量随缓冲头走 —— 装配期按 `CtrlBuffer.h` 的
`CTRL_TEXT_MULTI_BUF`(4096 字节)分配,见 `PrepareCtrlBuffer`;多行项尺寸 = 声明矩形。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

**操作码**:专属段 = `OPER_EDIT_SUBMIT`(与单行件同口径),搭载段恒 0;`param` = `0`。

行内回车 = 换行(不提交);提交 = 失焦且有改动。无专用缓冲时与单行件同法按只读占位绘制。

## InputReal 函数 (Controls)

绘制实数输入控件。

### 语法

```cpp
VOID InputReal(CtrlInfo* info);
```

### 参数

`[in] info`

类型: **CtrlInfo\***

实数输入控件信息。缓冲须为单个 `DOUBLE`,且 `bufferInfo.size >= sizeof(DOUBLE)`;缓冲缺失或尺寸不足时
按只读占位绘制,不写回值。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

**操作码**:专属段 = `OPER_EDIT_SUBMIT`(失焦 / 回车 / 箭头调整时提交),公共段可带部件给出的公共位图,
搭载段恒 0;`param` = `0`。

数值编辑的显示格式为定点两位小数;输入法在项激活期被禁用(数值输入不需要 IME)。

## InputNumeric 函数 (Controls)

绘制整数输入控件。

### 语法

```cpp
VOID InputNumeric(CtrlInfo* info);
```

### 参数

`[in] info`

## ListRowDropOper 函数 (Controls)

把列表行拖拽落点换算成行件返回约定。

### 语法

```cpp
int64_t ListRowDropOper(DWORD dwSrc, DWORD dwRow, BOOL IsAfter);
```

### 参数

`[in] dwSrc`

类型: **DWORD**

源行号(被拖起的那一行)。只写入结果的 `bit[63:48]`,不参与目标插入位置的计算;与目标行号语义不同,
调用方不得用同一变量兼表两者。

`[in] dwRow`

类型: **DWORD**

放置目标行号(鼠标当前所在行)。决定目标插入位置:`dwRow`(插到该行之前)或 `dwRow + 1`(插到该行之后)。

`[in] IsAfter`

类型: **BOOL**

`TRUE` = 鼠标落在该行下半(插到该行之后);`FALSE` = 落在上半(插到该行之前)。

### 返回值

类型: **int64_t**

行件返回约定(四字段布局):`bit[15:0]` = `OPER_LIST_ROW_MOVED`;`bit[31:16]` = `0`(无公共码);
`bit[47:32]` = 目标插入位置;`bit[63:48]` = 源行号。恒非 0 —— 是否真正重排由事件处理函数决定。

### 注解

纯换算,不触碰 ImGui、不读鼠标:调用方须先自行确定目标行号与上 / 下半。绘制侧**唯一的落点换算口径**,
部件层与控件层都经本函数,勿在别处另写一份。

两个数据字段各按 16 位掩码写入 ⇒ 行号与目标插入位置须小于 65536(否则高位被截断,进位不会污染相邻字段)。

控件层据此折算操作码的规则见 `ListInput` / `ListCombo` 的注解:专属段 `OPER_LIST_ROW_MOVED` +
搭载段(目标插入位置)+ `param`(源行号)。

## ListInput 函数 (Controls)

布局列表的绘制入口。

### 语法

```cpp
VOID ListInput(CtrlInfo* info);
```

### 参数

`[in] info`

类型: **CtrlInfo\***

列表控件信息。缓冲须含 `ListBuffer` 头(见 `ControlSpec.h`)与紧随其后的行数据区;缓冲缺失或尺寸不足时
仍维护列表壳体(画列表、无行),不报错。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

**缓冲解析**:行数据区布局 = `[特殊行块 cbItem] + [项目块 cbItem × dwCapacity]`,行长由头部 `cbItem`
自描述;项目数取 `dwCount`,超过 `dwCapacity` 时按容量截断。行块内容 = `INPUT_ACTION` 块(见
`CtrlBuffer.h` 的 `CtrlInputActionData`),行件为可编辑输入动作行。行数据由该控件绑定的事件处理器在渲染前
填充,本函数只读缓冲。

**特殊行** = 新增行,位置为最后(按该类型的约定),高度 = 行高。

**操作码** —— 逐行收集后统一回调,收集口径 = 取最后一个非 0 值(本帧无码则不回调):

| 情形 | 专属段 | 搭载段 | `param` |
| --- | --- | --- | --- |
| 普通行内事件 | 空 | 行内部件码(搭载标志 = 操作码) | 该行行号 |
| 行被拖拽重排 | `OPER_LIST_ROW_MOVED` | 目标插入位置(搭载标志 = 数据) | 源行号 |

`data` = 控件缓冲。行件返回约定见 `Widgets.h` 的部件返回位表;落点换算见 `ListRowDropOper`。

**拖拽重排交互**:每行行首有拖拽把手(按下并拖动 = 拖动该行),整行为放置目标,鼠标落在行的上半 / 下半
⇒ 插入到该行之前 / 之后(拖到末尾 = 移到最后)。

业务状态(行游标、几何递增、操作码累积)归本控件;列表子窗的容器状态由管道部件按稳定 ID 复用。

## GetCtrlApi 函数 (Controls)

取控件库的控件绘制接口表。

### 语法

```cpp
CONST CtrlApi* GetCtrlApi();
```

### 参数

无参数。

### 返回值

类型: **CONST CtrlApi\***

进程级静态的控件绘制接口表(3 项: `UpdateContext` / `DrawCtrl` / `HasActiveInput`)。表由控件库一次性填好,
重复调用返回同一张表(幂等);不会返回 `NULL`。

### 注解

本表是控件库对布局层暴露绘制能力的唯一入口:宿主在 UI 设施初始化期调用 `LayoutRender::SetCtrlApi(Controls::GetCtrlApi())`
注入,布局渲染出口此后只经表调用 —— 控件库因此不再暴露 3 项能力的直调路径给布局层, 换控件实现只改注入方。
控件上下文与逐控件绘制仍由本模块实现, 坐标换算与事件派发语义不变。
