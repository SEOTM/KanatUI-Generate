# DocumentIO 模块 (src\app\DocumentIO.h)

## 概述

`DocumentIO` 是文件与文档之间进出的唯一落点: 载入族(文件 / 内存缓冲 → 文档)、新建、保存族(文档 → 文件)、
工程源保护、关联磁盘路径与未保存改动标记。层归属为 app 层, 只做入口选择与格式分派, 不实现任何一端。

四条边界:

1. **不持会话面状态**: 预览唯一基座、文档结构版本号、条目几何重算都不属本模块 —— 需要时经注入的会话面回调
   原位请求, 未注入即该项不驱动(数据面改动照常落定, 返回码不受影响)。
2. **不做四级探测**: 启动加载链的级序与内置资源取件归 `app\DocumentSource`; 本模块只提供“按路径载入”与
   “按内存缓冲载入”两个入口。
3. **不做解析与生成**: 读方向(内容嗅探 + JSON / bin 解析)归 `framework\LayoutSolver`, 写方向(规范 JSON / bin
   字节流 + 备份 + 临时文件 + 原子替换)归 `editor\LayoutWriter`。依赖方向为 `app → doc / framework / editor`,
   不引编辑器命令头(命令本体只以函数指针持有)。
4. **不做编辑命令**: “追加布局”的命令本体归 `editor\EditorCommands`, 本模块只经命令面回调请求。

文档承载者(`Document`)经 `SetDocument` 注入; 未注入时全部接口**显式降级**(返回 `FALSE` / `NULL` / 空动作,
静默), 不制造空态替身。解析产物、条目数组与路径串一律取自会话分配器, 本模块自身不做堆分配。全静态类,
构造与析构私有化 ⇒ 进程级单例语义; 本模块不含线程安全机制。

文件内的 `static` 工具件(条目解绑 / 扩展名判定 / 同文件判定)不立条。

本模块包含以下编程接口:

### 函数

| 函数 | 说明 |
| --- | --- |
| `SetDocument` | 注入文档承载者(`NULL` = 复位)。 |
| `SetSessionHooks` | 注入会话面回调三件套(可分别传 `NULL`)。 |
| `SetDocLayoutAdder` | 注入“追加布局”编辑命令(`NULL` = 复位)。 |
| `LoadDocument` | 打开布局文件并整体替换当前文档。 |
| `LoadDocumentFromMemory` | 同上, 数据来自内存缓冲。 |
| `BuildDocumentFromSolver` | 由已解析的中间态构建整份文档。 |
| `NewSolver` | 从分配器分配并构造一枚布局解析器。 |
| `NewDocument` | 新建空白文档替换当前文档。 |
| `SaveDocument` | 把当前文档中间态按目标扩展名分派写盘。 |
| `IsEngineSourcePath` | 判断路径是否指向工程源文档。 |
| `IsProtectedSavePath` | 判断保存目标是否受保护。 |
| `GetDocPath` | 取当前文档关联的磁盘路径。 |
| `SetDocPath` | 写当前文档关联的磁盘路径(池化复制)。 |
| `MarkDocDirty` | 置“未保存改动”标记。 |
| `ClearDocDirty` | 清“未保存改动”标记。 |

## SetDocument 函数 (DocumentIO)

注入文档承载者。

### 语法

```cpp
static VOID SetDocument(
  [in] Document* pDocument
);
```

### 参数

`[in] pDocument`

类型: **Document\***

文档承载者地址; 传 `NULL` 表示复位(未注入)。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

**注入时序**: 应用侧在成员存储分配之后、启动加载链之前就地注入 —— 承载者按值内嵌在成员块内, 早于该步取不到
地址。`Release` 与应用启动失败后的清理路径均以 `NULL` 复位(承载者随分配器失效, 不复位即留悬垂指针)。

**装配顺序(分配器)**: `AllocatorHub::Init` → `Layout::SetAllocators` / `LayoutModel::SetAllocators` /
`ProjCR::SetAllocators`(同源同批) → 才可 `CreateLayout` / `StateInit`, 顺序不可颠倒。承载者注入与后续的
载入 / 新建都在这条序列之后就位: 分配器未建立时, 本模块的载入族与新建入口一律失败(判据见 `NewSolver` 与
`LoadDocument`)。

未注入时全部接口显式降级, 不抛异常、不诊断。

## SetSessionHooks 函数 (DocumentIO)

注入会话面回调三件套。

### 语法

```cpp
static VOID SetSessionHooks(
  [in] pfnEnsurePreviewBase      pfnEnsure,
  [in] pfnBumpDocRev             pfnBumpRev,
  [in] pfnRecalcEntryGeometry    pfnRecalcEntry
);
```

### 参数

`[in] pfnEnsure`

类型: **pfnEnsurePreviewBase**

预览唯一基座的取 / 建回调; 建立后让全部文档条目的布局指针指向该基座。传 `NULL` ⇒ 该项不驱动。

`[in] pfnBumpRev`

类型: **pfnBumpDocRev**

文档结构版本号递增回调(UI 缓冲同步信号)。传 `NULL` ⇒ 该项不驱动。

`[in] pfnRecalcEntry`

类型: **pfnRecalcEntryGeometry**

条目几何重算回调(依条目参考尺寸重建窗口几何与内部参考)。传 `NULL` ⇒ 该项不驱动。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

三者由应用侧在注入承载者的**同一点**注入, 指向会话面模块的静态实现; 三者可分别传 `NULL`, 各自独立降级。
未注入的效果是“跳过该步会话面驱动”: 数据面改动照常落定, 返回码不受影响 —— 只有命令面回调未注入才会让新建
中止(见 `SetDocLayoutAdder`)。

回调指向静态成员函数, 恒有效, 因此**不随** `Release` 复位; 三者的调用位置见 `BuildDocumentFromSolver` 与
`NewDocument` 的注解。

## LoadDocument 函数 (DocumentIO)

打开布局文件并整体替换当前文档。

### 语法

```cpp
static BOOL LoadDocument(
  [in] LPCSTR path
);
```

### 参数

`[in] path`

类型: **LPCSTR**

源文件路径; 空指针拒绝。

### 返回值

类型: **BOOL**

`TRUE` = 已载入; `FALSE` = 承载者未注入、分配器未就绪、路径为空、解析失败或构建失败。失败时**旧文档保持不变**。

### 注解

流程: 分配一枚解析器 → 解析文件(布局规格全部拷贝进分配器, 可长期持有) → 由中间态构建整份文档。成功后把关联
路径置为该路径并清脏标记(载入即“无未保存改动”); 激活索引由构建步骤置 `0`。

**形态由内容嗅探判定, 与扩展名无关**: JSON 文档(`layouts` 数组, 每项含布局名 / 显示名 / 窗口属性 / 参考
尺寸 / 自动尺寸 / 控件声明)与 bin 文档(格式版本 v1)走同一入口, 跳过 BOM 与空白后首字节为 `'{'` ⇒ JSON,
否则按 bin 解析。

失败口径统一为“拒绝该来源”: 解析或构建失败不影响当前文档, 调用方可按启动加载链的既有口径回落下一级来源。
路径入口在读毕即关文件, 载入被拒时不遗留句柄。

## LoadDocumentFromMemory 函数 (DocumentIO)

由内存缓冲载入文档。

### 语法

```cpp
static BOOL LoadDocumentFromMemory(
  [in] LPVOID pData,
  [in] DWORD  cbData
);
```

### 参数

`[in] pData`

类型: **LPVOID**

缓冲首址; 空指针拒绝。

`[in] cbData`

类型: **DWORD**

缓冲字节数; `0` 拒绝。

### 返回值

类型: **BOOL**

`TRUE` = 已载入; `FALSE` = 承载者未注入、分配器未就绪、入参非法、解析失败或构建失败。失败时旧文档保持不变。

### 注解

与 `LoadDocument` 同流程、同形态嗅探规则, 差别有二: 来源是内存缓冲(启动加载链第 3/4 级的内置资源走此入口);
成功后**清空**关联磁盘路径(内存载入无关联文件)并清脏标记。

**JSON 形态要求缓冲以 `'\0'` 结尾**(解析入口按 NUL 结尾的字符缓冲工作), 调用方负责补齐; bin 形态按字节数
直接解析。

## BuildDocumentFromSolver 函数 (DocumentIO)

由已解析的中间态构建整份文档。

### 语法

```cpp
static BOOL BuildDocumentFromSolver(
  [in] LayoutSolver* solver
);
```

### 参数

`[in] solver`

类型: **LayoutSolver\***

已解析完成的布局解析器(其状态为待接管的中间态); 空指针拒绝。

### 返回值

类型: **BOOL**

`TRUE` = 已整体替换当前文档; `FALSE` = 承载者未注入、分配器未就绪、解析器为空、布局数为 `0`、结构件排布
违规、条目构建或分配失败。失败时**旧文档保持不变**, 条目数组仅在全部条目建成后才提交。

### 注解

**步骤 0(载入前的唯一关卡) = 结构件排布体检**: 逐布局只读校验 —— 结构件须占布局头部连续槽位, 顺序为
`WND → [TITLE] → CNTR`, 各至多一枚, 内容控件只能排在其后。违规即打印逐条诊断并整份拒载(不替换当前文档),
调用方据此按“载入被拒”回落下一级来源。违规布局的后果是把结构件当内容控件渲染或渲染为空, 因此不静默容忍。

**步骤 1 = 中间态接管**: 先整份释放旧中间态(块与链节点归还小对象池), 再把解析产物作为当前中间态。内嵌(flex)
成员不随文档变化(其来源是外壳源, 节点生存期等于应用线性分配器) ⇒ 本处不释放、不重建。

**步骤 2 = 条目数组**: 从 `Arena` 一次性分配 `LayoutEntry × 布局数`。

**步骤 3 = 逐条目构建**: 按中间态布局节点填充条目 —— 布局名与显示名经分配器池化复制、窗口属性与参考尺寸照抄、
桌面位置照抄(文件可省略, 缺省 `0`)、中间态节点指针挂接、布局指针先置 `NULL`(布局对象 = 预览唯一基座, 由第
4-bis 步统一指向)。几何系数留在中间态元素规格内, 不逐枚写入条目。任一条目建不出即回滚已建条目并整体放弃。

**步骤 4 = 整体替换**: 先解绑旧条目的布局引用, 再经承载者的提交口整体替换条目数组(纯字段写入, 不做池分配
与回收), 随后请求文档结构版本号递增。

**步骤 4-bis = 预览基座**: 请求“取 / 建预览基座”, 建立后让全部文档条目的布局指针指向它(经会话面回调;
未注入则跳过, 条目的布局指针保持 `NULL`)。

**步骤 5 = 条目几何**: 逐条目请求几何重算(经会话面回调; 未注入则该轮不重算), 激活条目的控件内容由预览同步
路径装配。

激活索引置 `0`。预览选中态表达件在链外(编辑器自持) ⇒ 文档整体替换时本模块无需清理任何附加件。

## NewSolver 函数 (DocumentIO)

从分配器分配并构造一枚布局解析器。

### 语法

```cpp
static LayoutSolver* NewSolver();
```

### 参数

此函数无参数。

### 返回值

类型: **LayoutSolver\***

解析器指针; `NULL` = 线性分配器未就绪、分配失败或分配到的块小于解析器尺寸。

### 注解

在分配到的块上就地构造解析器, 解析产物长期持有。解析器所在内存随分配器整体释放, 不单独归还; 因此重复调用会
持续占用分配器, 调用方应在“载入一份文档”的粒度上使用。

本函数是分配器就绪性的判据点: 分配器未建立即必然返回 `NULL`, 载入族随即失败。

## NewDocument 函数 (DocumentIO)

新建空白文档替换当前文档。

### 语法

```cpp
static BOOL NewDocument();
```

### 参数

此函数无参数。

### 返回值

类型: **BOOL**

`TRUE` = 已新建并激活默认布局; `FALSE` = 承载者未注入, 或命令面回调未注入 / 失败(新建中止)。

### 注解

步骤: 清空旧条目(逐条解绑布局引用, 条目指针与条目数清零; 激活索引不在该处改动) → 整份释放旧中间态并置零
(新建文档不带旧布局模型) → 清空关联磁盘路径 → 清脏标记 → 经命令面回调追加默认布局(名字 `NewLayout`) →
激活索引置 `0` → 请求版本号递增。

**未注入命令面回调或回调返回失败即整步中止**并返回 `FALSE`: 不以空文档顶替, 也不留下“条目已清空、默认布局
缺失”的半成品给调用方使用。

条目数组所在内存由分配器持有, 本函数只把指针与计数清零, 不逐块归还; 内嵌(flex)成员不随文档变化, 不在此
释放。预览选中态表达件在链外, 新建时无需清理附加件。

## SaveDocument 函数 (DocumentIO)

把当前文档中间态写盘。

### 语法

```cpp
static BOOL SaveDocument(
  [in] LPCSTR path
);
```

### 参数

`[in] path`

类型: **LPCSTR**

目标文件路径; 空指针或空串拒绝。

### 返回值

类型: **BOOL**

`TRUE` = 已写入; `FALSE` = 承载者未注入、路径非法、目标受保护、生成或写盘失败。失败时原文件不变。

### 注解

**工程源保护在任何写盘动作之前判定**: 目标受保护即打印诊断并返回 `FALSE`, 不产生临时文件、不改动任何文件。

**格式分派(只取文件名部分的扩展名)**: `.bin`(大小写不敏感)⇒ bin 字节流(格式版本 v1); 其余一律 ⇒ 规范
JSON 文本。两条写盘链共用同一副骨架, 由写方向模块实现:

1. **备份**: 目标已存在且 `<目标>.bak` 不存在 ⇒ 复制一份(.bak 已存在时不覆盖; 备份失败只诊断, 不阻断写入)。
2. **正文**: 写同目录 `<目标>.tmp`(写满校验)并刷盘。
3. **替换**: 以“替换已存在 + 直写”的方式原子替换为目标文件。
4. **失败**: 删除残留 `.tmp` + 打印诊断(含系统错误码), **不弹窗**, 原文件不变; 目标路径过长时同样拒绝。

写出内容是整份文档: 全部布局 + 各自自动尺寸(含模式 / 单位 / 各项参考量) + 控件声明。写盘成功后把关联路径置为
该路径并清脏标记。

## IsEngineSourcePath 函数 (DocumentIO)

判断路径是否指向工程源文档。

不做存在性检查: 路径可以指向尚不存在的文件, 判据只看身份。

## IsProtectedSavePath 函数 (DocumentIO)

判断保存目标是否受保护。

### 语法

```cpp
static BOOL IsProtectedSavePath(
  [in] LPCSTR path
);
```

### 参数

`[in] path`

类型: **LPCSTR**

保存目标路径。

### 返回值

类型: **BOOL**

`TRUE` = 受保护(`SaveDocument` 拒绝写盘); `FALSE` = 不受保护, 或承载者未注入。

### 注解

判据是**两条同时成立**: 目标是工程源文档(见 `IsEngineSourcePath`), **且**当前文档的关联路径经规范化后与之
相同 —— 语义为“这份文档本来就来自该工程源文件”。来源是其它文件、内置资源或新建的文档, 即使另存到工程源
路径也不受保护(那属显式另存, 由人决定)。

工程源的改动只能由人手工进行。判据只读: 本函数不改动文档、不写盘、不诊断。

## SetDocPath 函数 (DocumentIO)

写当前文档关联的磁盘路径。

### 语法

```cpp
static VOID SetDocPath(
  [in] LPCSTR path
);
```

### 参数

`[in] path`

类型: **LPCSTR**

新的关联路径; `NULL` 或空串表示清空关联。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

非空串经分配器池化复制后写入承载者 ⇒ 入参可以是临时缓冲, 调用方在返回后即可释放。承载者未注入时为空操作。

本模块在载入成功(置来源路径)、内存载入成功(清空)、新建(清空)、保存成功(置保存路径)四处调用; 池化使旧串
不被回收而是随分配器整体释放。

## MarkDocDirty 函数 (DocumentIO)

置“未保存改动”标记。

### 语法

```cpp
static VOID MarkDocDirty();
```

### 参数

此函数无参数。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

标记本体与判据在文档承载者, 本函数只转发。置脏时机是所有会改动文档内容的编辑动作(控件增删改、布局增删改、
文本 / 事件 / 几何提交、列表操作、标识重排); **尺寸轴切换不置脏**。承载者未注入时为空动作。

标记用于“关闭 / 新建 / 打开”前的提醒分流: 有改动才提示, 无改动零提示。

## ClearDocDirty 函数 (DocumentIO)

清“未保存改动”标记。

### 语法

```cpp
static VOID ClearDocDirty();
```

### 参数

此函数无参数。

### 返回值

类型: **VOID**

此函数不返回值。

### 注解

清脏时机有四处, 且全部由本模块在数据面落定之后调用: 文件载入成功、内存载入成功、新建、写盘成功。写盘失败或
载入被拒**不**清脏。

承载者未注入时为空动作。
